# Codelit for Mac releases

This is the official public distribution repository for the Direct edition of
[Codelit for Mac](https://codelit.io/docs/codelit-for-mac).

**Status:** no production build has been released yet.

When a release is available, its GitHub release contains the immutable,
Developer ID-signed and Apple-notarized app archive, disk image, checksums,
software bill of materials, signed provenance, and release metadata. Published
release assets cannot be replaced.

The `latest.json` file on `main` is the Direct edition's update activation
pointer. It advances only after the complete release has passed independent
signature, checksum, provenance, and anonymous-download verification. A
published release without that pointer is inert to installed clients.

Mac App Store builds are distributed by Apple and are not published here.

For product help, visit the [Codelit for Mac guide](https://codelit.io/docs/codelit-for-mac).
Report security issues privately through this repository's **Security** tab.
