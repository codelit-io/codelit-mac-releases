# Security policy

Please do not disclose a suspected vulnerability publicly.

Use **Security > Report a vulnerability** in this repository to send the
details privately. Include the affected Codelit version, macOS version,
reproduction steps, and the expected and observed behavior. Do not include API
keys, provider credentials, browser data, private workspace content, or other
user data.

Only versions offered by the current `latest.json` pointer are supported. No
production version has been released yet.
